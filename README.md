# Village Run (Android)

An endless runner across 24 Indian cities, packaged for Google Play with Capacitor 8.

**Play in the browser:** https://absolutely-sharad.github.io/village-run/
**Privacy policy:** https://absolutely-sharad.github.io/village-run/privacy-policy.html

## Put it on GitHub (first time)

1. On github.com, create a **new public repository** named `village-run` under `absolutely-sharad`. Leave it empty (no README, no .gitignore, no licence).
2. Unzip this project, open a terminal in the `villagerun` folder (it already contains a git history) and run:

   ```
   git remote add origin https://github.com/absolutely-sharad/village-run.git
   git push -u origin main
   ```

3. In the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Open the **Actions** tab. "Deploy the game to GitHub Pages" runs on every push; after about a minute the game is live at the link above. (If the first run started before step 3, open it and click **Re-run all jobs**.)

On phones, open the link in Chrome and choose **Add to Home screen** to install it like an app.

## What's in here

- `www/` — the game (one HTML file plus bundled fonts). Works fully offline.
- `android/` — the native Android project generated by Capacitor.
- `.github/workflows/android-release.yml` — builds the signed `.aab` on GitHub.
- `docs/privacy-policy.html` — the privacy policy to host with GitHub Pages.

## Build the signed app bundle on GitHub (recommended)

1. Create a **private** GitHub repository and push this folder to it.
2. In the repository: **Settings → Secrets and variables → Actions → New repository secret**. Add four secrets, using the values from the private key folder you were given (never commit them):
   - `UPLOAD_KEYSTORE_BASE64`: the full contents of `village-run-upload.jks.base64.txt`
   - `UPLOAD_KEYSTORE_PASSWORD`: the password
   - `UPLOAD_KEY_ALIAS`: `villagerun-upload`
   - `UPLOAD_KEY_PASSWORD`: the same password
3. Open the **Actions** tab, choose **Build Android release (AAB)**, then **Run workflow**.
4. When it finishes (about 5 minutes), download **village-run-release-aab** from the run page. Inside is the `.aab` to upload to Play Console.

Each run gets a higher versionCode automatically, so every new build can be uploaded as an update.

## Build in Android Studio instead

1. Install Node.js 22 and Android Studio (with the Android 16 / API 36 SDK).
2. In this folder: `npm install`, then `npx cap sync android`.
3. Copy `android/keystore.properties.example` to `android/keystore.properties` and fill in the real path and password.
4. Open the `android` folder in Android Studio, then **Build → Generate Signed App Bundle** (or run `./gradlew bundleRelease` in `android/`).
5. The bundle is at `android/app/build/outputs/bundle/release/app-release.aab`.

## Changing the game

Edit `www/index.html`, then run `npx cap sync android` before building. Raise `versionName` in `android/app/build.gradle` for each public release.

## Privacy policy hosting

The Pages workflow publishes `docs/privacy-policy.html` next to the game, so the policy URL for Play Console is
`https://absolutely-sharad.github.io/village-run/privacy-policy.html`.
